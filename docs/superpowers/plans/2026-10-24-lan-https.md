# 内网 HTTPS Implementation Plan

> **For agentic workers:** 在本会话按任务顺序执行；用户已授权更改。无需子代理。

**Goal:** 让局域网 IP 使用受信 HTTPS，管理员可设置模型下载密码，成员仅校验后下载。

**Architecture:** 已有 Node HTTPS 直连；固定版本 mkcert 生成部署私有 CA；Compose 只读挂载服务证书；设备显式信任公开根证书；复用 owner 权限。

**Tech Stack:** Windows PowerShell 5.1、mkcert 1.4.4、Node HTTPS、Docker Compose、Node test。
