# 初始化令牌一键获取工具设计

## 目标

为不熟悉部署流程的 Windows 管理者提供一个可双击运行的脚本，从项目根目录的 `.env` 读取 `BOOTSTRAP_TOKEN`，在终端显示令牌并自动复制到系统剪贴板，方便首次在客户端创建 Owner。

## 范围

- 新增项目根目录入口脚本 `获取初始化令牌.bat` 和实现脚本 `获取初始化令牌.ps1`。
- 脚本从自身所在目录定位 `.env`，不依赖当前工作目录。
- 成功读取后显示完整令牌并复制到 Windows 剪贴板。
- 缺少 `.env`、缺少 `BOOTSTRAP_TOKEN` 或令牌为空时，显示中文错误和处理建议，并返回非零退出码。
- 不修改 `.env`，不生成包含令牌的新文件，不主动写入日志。
- 在终端提示：令牌仅用于首次创建 Owner；初始化完成后服务端会拒绝再次使用，但 `.env` 中的配置仍应按密钥处理。

## 方案

使用一个薄的 `.bat` 入口调用同目录 PowerShell 实现脚本。这样普通用户可以直接双击使用，同时不引入额外运行时依赖。独立的 `.ps1` 文件避免 `cmd.exe` 错误解析 PowerShell 命令中的管道符，并使用 Windows PowerShell 5.1 可识别的 UTF-8 BOM 编码。PowerShell 负责安全读取 `.env`、解析精确的 `BOOTSTRAP_TOKEN=` 行，并通过 `Set-Clipboard` 复制令牌。

令牌值只在进程内存和系统剪贴板中短暂出现；脚本不打印调试信息、不把值拼接进外部命令参数，并在成功后暂停窗口，确保用户能看到结果。

## 错误处理

- `.env` 不存在：提示从部署项目根目录运行。
- 找不到 `BOOTSTRAP_TOKEN=`：提示先运行配置初始化流程。
- 值为空：提示配置无效。
- 剪贴板复制失败：仍显示令牌，但明确提示需要手动复制，并返回非零退出码。
- 脚本结束前暂停，避免双击窗口立即关闭。

## 验证

通过 PowerShell 临时目录构造以下场景并检查退出码、输出和剪贴板结果：

1. 有效 `.env` 能显示令牌并复制到剪贴板。
2. 缺少 `.env` 会失败且不产生令牌输出。
3. 缺少或空的 `BOOTSTRAP_TOKEN` 会失败。

另外运行项目现有客户端和后端验证命令，确认没有影响既有功能。
