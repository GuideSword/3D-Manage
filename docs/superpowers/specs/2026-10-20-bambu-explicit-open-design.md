# 桌面 Web 显式交接 Bambu Studio（方案草稿）

日期：2026-10-20。状态：自动启动缺陷已修复并回归；新增交接功能待用户确认方案，尚未实现。

## 用户操作和范围

模型详情中每个源文件提供“在 Bambu Studio 中打开”。只有点击才允许交接，打开后导入该文件。多个源文件必须明确选择一个；点击期间防重复提交。上传、查看详情、生成预览和自动验收不得启动切片器。参数、切片和打印由用户在 Studio 手动完成，ERP不发送打印命令。

## 两种可选方案

1. 官方跳转链接：电脑已安装并注册 Studio 时无需额外助手；但不能保证覆盖当前STL/STEP等源文件。当前上游代码的网络导入路径检查3MF扩展名，对非信任来源另行确认；ERP文件需要认证，不能直接把现有受保护下载地址交给Studio，也不能把账号令牌放进链接。适合先做3MF限定版本，需核对已安装版本。
2. Windows本地导入助手（推荐用于全部常用模型格式）：电脑一次性安装/配置助手，Web显式点击后由助手下载已授权的指定文件，再把本地文件路径作为独立参数交给指定Studio程序。可避免官方网络导入对格式的限制；实际格式能力仍取决于已安装Studio版本。代价是额外维护本机助手，手机端不提供此入口。

单纯下载后让用户手动导入可作为失败备用操作，但不视为“打开并导入”功能已完成。后端若位于Docker/其他电脑，不能从后端启动Studio代替用户电脑导入。

## 推荐方案需要落实的边界

- 首次由用户设置Studio路径及允许的ERP服务器；不自动改系统STL/3MF文件关联，不自动安装或注册助手。
- 点击后服务器按当前账号权限签发短期、限定单个文件版本和内容hash的交接凭据；不使用登录令牌代替交接凭据。到期、撤销、切换服务器和重放行为应在实施设计中明确并测试。
- 助手只访问已配对服务器的文件接口，拒绝任意URL、任意程序/命令/本机路径；避免无鉴权的本机“打开文件”服务。协议注册/配对/凭据兑换需在实施计划前完成安全设计。
- 下载到助手专用目录并校验hash，完成后才调用固定Studio可执行文件；不经过Shell拼接，不传切片/打印参数。重复点击和已有Studio窗口的行为以已安装版本验收为准。
- 未安装、未配对、下载失败、无权限和不支持格式分别提示并保留普通下载入口；不显示虚假的“已导入”。助手成功启动与Studio实际完成导入分别验收。
- 自动测试只拦截启动调用和检查参数，不打开真实Studio；真实导入只在用户指定后进行，打印不在验收范围。

## 已确认的缺陷修复

自动预览已移除Windows Shell缩略图调用；3MF内嵌图保留，无图时允许手动加图。旧接口与关系模式均覆盖。文件模块44项回归通过、0跳过；当前源码修改未发布正式容器。
