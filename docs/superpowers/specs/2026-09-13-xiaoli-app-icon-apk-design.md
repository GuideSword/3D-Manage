# 小鲤 APP 图标与 Android 预览 APK 设计

## 目标

将现有小鲤角色作为 Android APP 图标，并生成可直接安装、无需 Metro 的预览 APK。此次交付用于内部安装与视觉验收，不作为应用商店正式发布包。

## 图标设计

- 使用 `assets/xiaoli/hero.png` 中的小鲤头像特写作为唯一角色来源。
- 重点保留猫耳耳机、银紫色头发和眼睛等高辨识度特征。
- 生成 1024×1024 普通图标和透明自适应前景图。
- 使用与现有小鲤界面一致的紫蓝渐变背景。
- 前景保留 Android 自适应图标安全边距，兼容圆形、圆角方形等启动器遮罩。
- 图标中不加入文字、小型装饰或 3D 立方体，避免缩小后模糊。

## 配置与构建

- 更新 Expo 可维护源配置及 `assets/icon.png`、`assets/adaptive-icon.png`。
- 将配置同步到现有 Android 生成目录，确保 `mipmap` 启动器资源使用新图标。
- 执行项目现有客户端验证，并通过本地 Gradle `release` 任务生成独立 APK。
- 沿用当前 Android application ID `com.anonymous.x3DManage`，不改变升级身份。
- 沿用当前本地预览构建方式，以 Android 调试证书签名 release 变体；该签名只适合预览和内部测试。

## 产物与验证

- 将 APK 复制到 `output/releases/`，文件名包含应用、版本和小鲤预览标识。
- 验证 APK 文件存在且非空、签名可校验，并记录 SHA-256、字节数和构建时间。
- 检查 APK 内的启动器图标资源已经更新。
- 若存在可用 Android 设备，则安装并确认桌面图标；若没有设备，明确记录真机安装与视觉验收尚未完成。

## 非目标

- 不创建正式生产签名或上传应用商店。
- 不生成 AAB。
- 不更改包名、版本策略、业务功能或后端部署。
- 不提交 APK、大型生成目录或签名凭据到 Git。

## 验收标准

1. 普通图标与自适应图标均显示选定的小鲤头像特写。
2. 客户端验证通过，release APK 构建成功。
3. APK 可独立运行，不依赖 Metro。
4. APK 签名校验通过，并提供本地绝对路径、大小和 SHA-256。
5. 真机验收状态如实记录，不以编译成功代替安装验证。
